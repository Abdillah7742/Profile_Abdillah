## 📌 Tentang Proyek

Repositori ini berisi kode sumber untuk website portofolio personal milik **Muhammad Abdillah Ahmad**, mahasiswa semester 7 Teknik Komputer dan Jaringan (TKJ) di Politeknik Negeri Ujung Pandang. Website ini dirancang sebagai pusat pameran digital untuk menampilkan riwayat pendidikan, proyek-proyek PBL (Project-Based Learning), riwayat pengalaman kepanitiaan/organisasi, serta sertifikasi keahlian.

* **Alamat Website Resmi**: [https://abdillah.techmaestro23.my.id](https://abdillah.techmaestro23.my.id)

---

## ✨ Fitur Utama & Desain Visual

| Fitur | Deskripsi |
|---|---|
| 🗃️ **Dynamic JSON Architecture** | Seluruh konten (biodata, pendidikan, proyek, pengalaman, sertifikat) dimuat secara dinamis dari berkas `data.json` tanpa perlu menulis ulang HTML. |
| 🎓 **Interactive Education Timeline** | Riwayat pendidikan yang divisualisasikan dalam bentuk vertical timeline interaktif berseling yang estetis. |
| 🖼️ **1:1 Experience Gallery Grid** | Bagian pengalaman disajikan dalam tata letak kartu visual 1:1 modern dengan text overlay gradasi gelap, dilengkapi fallback kontainer siber premium untuk item tanpa foto. |
| 🔍 **Immersive Detail Modals** | Popup modal interaktif untuk melihat rincian lengkap proyek dan pengalaman, dilengkapi galeri foto masonry multi-rasio non-cropping dan tautan dokumentasi video/sosial. |
| ⚖️ **Centered Wrap Alignments** | Sisa kartu pada baris terakhir di bagian Projects, Experience, dan Certificates otomatis bergeser rata tengah menggunakan sistem Flexbox dinamis untuk keseimbangan visual. |
| ⚡ **WebP Performance Optimization** | Seluruh aset gambar dikonpresi ke format modern `.webp` untuk memastikan performa pemuatan halaman yang sangat instan dan ringan. |
| 🐳 **Dockerized Deployment** | Kontainerisasi penuh menggunakan Nginx dan integrasi alur otomatisasi rilis dengan GitHub Actions CI/CD. |

---

## 🏗️ Tech Stack

* **Frontend**: HTML5, Vanilla JavaScript (ES6+), CSS3 (Tailwind CSS v4)
* **Design/Icons**: Phosphor Icons, FontAwesome
* **Aset Optimasi**: WebP (ImageMagick/Pillow)
* **Server & Deployment**: Nginx, Docker, Docker Compose, GitHub Actions (CI/CD)
